01 / What it does

One place for all of them.

  • 01

    Every app in one list

    See which Craft apps you have, which version each one is on, and which ones you could add.

  • 02

    Update notifications

    Checks for new releases every few hours and shows a Windows notification when there's an update.

  • 03

    A download queue

    Queue installs and updates for as many apps as you like. They download one at a time and install in order.

  • 04

    Verified downloads

    Each installer is checked against its published SHA-256 checksum before it runs.

  • 05

    Official installers

    Apps install with their own installers into Program Files, with Start menu entries, and uninstall from Windows Settings like any other app.

  • 06

    Stays out of the way

    Closing the window keeps it in the system tray. Starting with Windows is optional and off until you turn it on.

04 / Questions

Questions.

Do I need a GitHub account?

No. The manager reads release information from GitHub's public API, without signing in.

Where do the apps go?

Each app installs with its own official installer into C:\Program Files, with a Start menu entry, just as if you'd downloaded it yourself. Windows asks for permission each time.

What happens to the old version when I update?

The new version replaces it, so you only ever have one copy of each app.

Does it run all the time?

Closing the window keeps it in the system tray so it can check for updates. To stop it, choose Quit from the tray icon. It only starts with Windows if you turn that on in its Settings.

How do I update the manager itself?

Download the latest installer from this page and run it. It replaces the version you have.

How do I remove it?

Uninstall ArtCraft Apps Manager from Settings › Apps › Installed apps. The apps you installed with it stay installed.

The apps are created, published and supported by their developers at getartcraft.com. The manager downloads each app from its official release on GitHub and installs it unchanged.
